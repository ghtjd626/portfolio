# ADR-0008 — 디자인 정체성 v2 + 홈 시그니처 인터랙션 "The Stream"

- **상태:** Accepted (웹)
- **날짜:** 2026-07-27
- **관련:** ADR-0007(CSS 토큰), ADR-0001(핵심 통찰), ux-principles.md

## What — 무엇을 결정하는가

1. 웹의 시각 정체성을 **v2**로 교체한다: **그래파이트 뉴트럴 + 앰버(琥珀) 시그널 + 모노스페이스 구조 목소리**. 색은 "내 기록 종류"가 가져온다.
2. 홈에 **시그니처 인터랙션 "The Stream"** 을 둔다 — 모든 기록 종류가 하나의 시간축을 공유하는 것을 손수 만든 인터랙티브 시각화로 보인다.

## Context — 배경

- v1 디자인(인디고 카드 · 둥근 모서리 · **왼쪽 액센트 바** · 소프트 섀도우 · 시스템 산세리프)은 정확히 지금 흔한 **AI 생성 디자인 클리셰**였다. 브리프 §동기("AI로 만든 것 같지 않게")와 정면으로 어긋난다.
- 프론트엔드 역량을 드러낼 **시그니처 인터랙션**이 없었다.

## Considered Options

**정체성**
- 제네릭 SaaS 유지 — 빠르지만 차별성 0(탈락).
- **앰버·그래파이트·모노 "인스트루먼트/로그"(채택)** — "Lore = 내 삶의 로그"에서 도출. 앰버=기록/보존(琥珀), 모노=시스템/로그, 색=내 데이터.

**홈 인터랙션**
- 정적 대시보드 — 무난하나 밋밋.
- 기여도 히트맵 — 흔하고(트로프) 통찰을 담지 못함.
- 물리 오브/파티클 — "AI 데모" 느낌이 강함(탈락).
- **시간축 스트림 "The Stream"(채택)** — ADR-0001의 핵심 통찰을 그대로 시각화.

## Why — 근거

- **의미로부터 온 정체성.** 팔레트·타이포가 주제(기록/시간/소유)에서 도출됐다. 클리셰(둥근카드+액센트바)를 의도적으로 제거.
- **인터랙션이 논지를 말한다.** "모든 종류가 하나의 시간축을 공유"(동적 스키마를 데이터로, ADR-0001)를 화면에서 보게 한다. 장식이 아니라 **주장의 시각화**.
- **프론트엔드 크래프트 증명.** 관성 스크러빙 · 포인터 자기장(magnetism) · "지금" 펄스를 rAF로 직접 구현. local-first의 즉시성과 결이 같다.

## How

- CSS 토큰 v2(라이트/다크), 헤어라인·샤프 모서리, 카탈로그형 종류 타일(스와치).
- **이모지 → 직접 만든 라인 아이콘 세트**(`components/icons.tsx`). 이모지는 대표적 "AI 생성" 신호라, 24×24 stroke 아이콘 세트로 교체하고 종류 아이콘은 아이콘 피커로 고른다(레거시 이모지는 하위호환 렌더).
- `LifeStream`: requestAnimationFrame 루프에서 DOM transform 직접 갱신(관성·자기장). **reduced-motion·터치(수평 팬)·키보드** 대응. 마크는 접근 가능한 `<button>`.

## Trade-off / Consequences

- **좋은 점:** 뚜렷한 정체성 + 기억에 남는 인터랙션 + 논지의 시각적 증거.
- **감수하는 비용:** 손수 만든 인터랙션은 유지보수 코드가 는다. 기록이 수백 개를 넘으면 가상화가 필요(현재는 충분). 이 UI는 **웹 전용**이라 네이티브 앱에선 다시 설계해야 한다.

## Counterfactual

- 만약 **네이티브 앱을 먼저** 세웠다면(Tamagui, ADR-0005), 이 웹 전용 인터랙션 대신 유니버설로 구현할 방법부터 찾았을 것이다. **웹 우선 MVP**라 지금은 웹 플랫폼의 강점(포인터·rAF·CSS)에 최적화하는 게 옳다. 네이티브 단계에서 재해석하며 이 ADR을 재검토한다.
